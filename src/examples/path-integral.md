# Feynman Path Integral

## Equation

$$
\mark[amplitude]{K(b,a)} = \mark[paths]{\int_a^b \mathcal{D}[x]}\, \mark[phase]{e}^{\mark[phase]{i}\,\frac{\mark[action]{S[x]}}{\mark[planck]{\hbar}}}
$$

## Description

To find [the quantum amplitude]{.amplitude}, [add contributions from every possible path]{.paths}, with [phases]{.phase} set by [each path's action]{.action} in units of [the reduced Planck constant]{.planck}.

## .amplitude

An amplitude carries both strength and phase. Keeping the phase lets different ways of arriving reinforce or cancel before we calculate probabilities.

## .paths

Direct routes, detours, and paths that double back all contribute. The integral gathers them into a single amplitude for the journey.

## .phase

Changing the action shifts the phase without changing the size of the contribution. A half-cycle shift changes reinforcement into cancellation.

## .action

For an ordinary particle, action adds up kinetic minus potential energy over the journey. Near a classical path, small changes to the route barely change the action, so nearby contributions tend to reinforce.

## .planck

Sets the scale converting action into phase. An action difference of $2\pi\hbar$ corresponds to a full cycle, so the two paths contribute in step.
